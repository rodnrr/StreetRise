# Example AI article body

This example shows the intended structure of `body_markdown` after the Worker quality update.

```markdown
## Event Details

- **Date:** Thursday, October 15, 2026
- **Time:** 5:00–7:00 PM
- **Location:** Dr. Michael Grego Leadership Institute

[Register for the event](https://example.org/register)

## What Families Can Expect

Use short paragraphs that add new information rather than restating the event details.

## Questions?

Email [volunteer@example.org](mailto:volunteer@example.org) for more information.
```

The example URL and email are placeholders for documentation only. The Worker may only use real URLs and contact information supplied in the generation brief.
